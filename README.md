
# Wazir Coding Company – Retail Sales Performance Dashboard

## Project Overview
This project presents an interactive Retail Sales Performance and Profitability Dashboard developed using Microsoft Excel.

The objective is to transform raw retail sales data into meaningful business insights to support management decision-making.

## Tools & Technologies
- Microsoft Excel 2024
- Power Query
- Power Pivot
- DAX Measures
- PivotTables and PivotCharts
- Advanced Excel Formulas
- Interactive Slicers and Timelines

## Project Features
- Data Cleaning and Transformation
- Sales and Profit Analysis
- Product Performance Analysis
- Customer Analysis
- Employee Performance Analysis
- Regional Sales Analysis
- Monthly Sales Trends
- Interactive Executive Dashboard

## Key Performance Indicators
- Total Revenue
- Total Profit
- Profit Margin
- Total Orders
- Average Order Value
- Average Selling Price
